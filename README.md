# BOUDEWARE — Mobile App

Application mobile officielle de **BOUDEWARE | En direct du Web**.

## Stack

- React Native
- Expo
- iOS + Android

## Concept

Une divertissante revue d'histoire culturelle : **4 générations, 3 thèmes — LET'S DANCE, LET'S FLY, LET'S FIGHT — 13 épisodes, 30 minutes.**

## Lancer localement

```bash
npm install
npx expo start
```

Puis ouvrir avec Expo Go, un simulateur iOS/Android ou un appareil compatible.
